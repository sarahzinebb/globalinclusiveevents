Politique de confidentialité

Comment nous traitons les informations que vous nous confiez. Dernière mise à jour : octobre 2026.

Qui nous sommes

Global Inclusive Events est une initiative de Global Premium Events, basée à Rabat, au Maroc. Contact : info@globalpremiumevents.com, +212 653512995.

Ce que nous collectons

Uniquement ce que vous nous envoyez via nos formulaires ou par e-mail : votre nom, vos coordonnées, le programme ou le service qui vous intéresse, votre message et, si vous choisissez de les partager, vos besoins d’accès. Nous utilisons ces besoins uniquement pour organiser votre participation.

Pourquoi nous les utilisons

  • Pour vous répondre et vous inscrire aux sessions
  • Pour prévoir les aménagements d’accessibilité que vous avez demandés
  • Pour vous envoyer les dates des sessions que vous avez demandées

Qui les reçoit

Uniquement notre équipe. Les messages des formulaires arrivent dans notre boîte via un service d’envoi de formulaires (FormSubmit). Le site est hébergé par GitHub Pages. Nous ne vendons ni ne louons de données personnelles et n’utilisons aucun traceur publicitaire.

Combien de temps nous les gardons

Les demandes sont supprimées sous 24 mois, sauf si vous participez à un programme : dans ce cas, nous gardons vos informations pendant la durée du programme et de nos obligations de reporting.

Vos droits

Selon la loi marocaine n° 09-08, et le RGPD pour les visiteurs de l’Union européenne, vous pouvez demander à accéder à vos données, les corriger ou les supprimer, ou vous opposer à leur utilisation, en écrivant à info@globalpremiumevents.com. Vous pouvez aussi contacter l’autorité marocaine de protection des données, la CNDP (www.cndp.ma).
